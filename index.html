Inicializando

El primer viaje del día sale desde aquí y el último termina aquí. Si lo dejas vacío, se usa NowCare.

Cómo obtener tu API key (5 min):
1. Entra a Google Maps Platform Console y crea un proyecto
2. En "APIs habilitadas", activa: Maps JavaScript API · Geocoding API · Distance Matrix API
3. En "Credentials", crea una API key y restringe por HTTP referrer al dominio donde subes el archivo
4. Google da $200 mensuales gratis · tu uso típico costará $0
